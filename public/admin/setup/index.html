Stripe + Cloudflare

Wire up payments

Paste two values, click the button. The Function creates a Stripe webhook, captures the signing secret, writes both secrets into this project's Cloudflare Pages env (Production + Preview), and triggers a redeploy. ~5 seconds end-to-end. No terminal.

1. Mint a Cloudflare API token

  1. Open Cloudflare API tokens in a new tab.
  2. Click Create Token → Create Custom Token.
  3. Add one permission: Account → Cloudflare Pages → Edit.
  4. Account Resources: include your account. Continue, then Create. Copy the token (revealed once).

This token is used in this one request and discarded — it’s not stored anywhere.

2. Find your Cloudflare account id

It’s a 32-character hex string visible at the bottom right of every page in the Cloudflare dashboard. Or go to dash.cloudflare.com → right sidebar → Account ID → copy.

3. Get your Stripe secret key

Open Stripe API keys. Reveal the Secret key (test or live mode — the wizard auto-detects) and copy it. The wizard prompts before any live-mode write.
